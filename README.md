# BluringCore
A theme for LiquidBounce(Minecraft Hack Client)

正如其名 这个主题的特色是模糊 还伴有适得其处的发光

这个主题包去除了标题屏幕上"没用"的东西 将标题屏幕变得更有逻辑性 更易用

ClickGUI改变了样式——更加易用并修复了原有ClickGUI的一个Bug

还改动了标题屏幕的背景

As the name suggests, the core feature of BluringCore is blur, complemented by well-placed glow effects.

This theme removes redundant elements from the title screen, making it cleaner, more logical, and easier to use.

The ClickGUI not only gets a visual overhaul, but also fixes a bug present in the original ClickGUI, making it more stable and responsive.

#Install
在游戏内执行.client theme browse

把zip压缩包在打开的文件夹里

解压 并确保index.html在themes/BluringCore/

在游戏内执行.client theme set BluringCore

In-game, run .client theme browse

Extract the zip archive in the opened folder

Make sure index.html is located in themes/BluringCore/

In-game, run .client theme set BluringCore

#Build
安装Node.js环境

在位于项目根目录的CMD里执行npm run build

编译结果在/dist

Install Node.js

Open CMD in the project root and run npm run build

The compiled output will be in the /dist folder
